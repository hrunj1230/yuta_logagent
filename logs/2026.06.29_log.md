## 💡 오늘 배운 것

### 1. 프로그래밍 언어의 객체 참조 이해
#### 내용
- Python에서 int는 immutable(불변객체)이기 때문에 포인터처럼 동작하지 않음
- 리스트는 mutable(가변객체)이므로 객체 자체를 수정 가능
- 파이썬의 모든 변수는 객체에 대한 참조를 가지고 있음
- Java의 Integer 캐싱: -128~127 범위는 재사용되지만, 범위를 벗어나면 새 객체 생성
- `==`는 객체를 비교, `equals()`는 값을 비교

#### 예제
```python
# Python 예제
a = 1
b = a
b = 3 
print(a)  # 출력: 1
# a -> 1
# b -> 1 (처음에는 같은 1을 참조)
# b -> 3 (int 3의 객체를 새로 생성해서 참조)
```

```java
// Java 예제
Integer x = 128;
Integer y = 128;
System.out.println(x == y);  // False
// 128은 캐시 범위(-128~127)를 벗어나므로 서로 다른 객체 생성
```

#### 참고
- Immutable vs Mutable 객체 개념
- Java Integer 캐싱 메커니즘

### 2. 리스트와 튜플의 차이
#### 내용
- **List**: 수정, 삭제, 추가 가능 (mutable)
- **Tuple**: 수정 불가능 (immutable)
- 데이터의 변경 가능성에 따라 적절한 자료구조 선택 필요

#### 예제
```python
# 단일 사용자 정보 - 수정이 필요 없을 수 있음
user = ("kim", 28)

# 여러 사용자 목록 - 추가/삭제/수정이 필요할 수 있음
users = [
    ("kim", 28),
    ("lee", 30),
    ("park", 25)
]
```

#### 참고
- 성능과 안정성 측면에서 tuple이 유리한 경우가 있음
- 변경 가능성이 있는 데이터는 list 사용
